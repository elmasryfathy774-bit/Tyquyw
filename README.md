## ما الذي حدث بالضبط (مهم)
1. **`index.html`**: الأصلي (Zewail Smart) أُبقي كما هو، وأضفت فقط `<script src="config.js">` قبل `script.js` ورابط «دخول الإدارة والمعلمين» في الفوتر. (الملف الأول الذي وصلني سابقًا كان لتطبيق AChat وليس لحضور، ولم أستخدمه.)

3. لم أحذف أي ميزة: الشات، بنك الكتب، المنصات، الترجمة، المفقودات، الملخصات، لوحة الشرف، المقترحات كلها كما هي.

## خطوات التشغيل
1. **أنشئ جدول Google Sheets جديد** بالأوراق في `schema.md`، وأنشئ له API في SheetDB.
2. انشر الـ Worker: `npx wrangler deploy` ثم أضف الأسرار (`SHEETDB_URL, TOKEN_SECRET, SETUP_KEY`) بأوامر `wrangler secret put` (مذكورة في `wrangler.toml`).
3. ضع رابط الـ Worker في `config.js`: `https://hudur-api.xxx.workers.dev/api`.
4. أنشئ أول مدير مرة واحدة (غيّر القيم):
```
curl -X POST https://hudur-api.xxx.workers.dev/api/setup -H "Content-Type: application/json" -d '{"setup_key":"..","username":"admin","password":"كلمة-قوية-8+","name":"مديرة المدرسة"}'
```
ثم **احذف السر SETUP_KEY**. ارفع الملفات على GitHub Pages.
5. ادخل `admin.html` ← تبويب «الطلاب» ← «استيراد» وارفع `students.csv` (148 طالبة؛ منهم **2 بدون رقم ولي أمر**: 475220851 و475012184).
6. من «الإعدادات»: حد الإنذار، المواد (الدرجة النهائية والوزن)، العطلات. من «المستخدمون»: أنشئ المعلمين وحدد فصولهم.

## كيف يُحسب الغياب
- **أيام الدراسة الفعلية** = الأيام التي سُجّل فيها حضور لفصل الطالب فعلًا، بعد استبعاد الإجازة الأسبوعية (الجمعة والسبت افتراضيًا) والعطلات المسجلة. يوم لم يُسجَّل لا يُحسب حضورًا ولا غيابًا.
- نسبة الغياب = أيام الغياب ÷ أيام الدراسة المتاحة للطالب × 100. الغياب **بعذر** يُخصم من أيامه المتاحة ولا يُحتسب غيابًا.
- الإنذار: يُنشأ تلقائيًا عند حفظ الحضور إذا بلغ غياب العام الحد (افتراضي 15، قابل للتعديل). لا يتكرر لنفس الطالب إلا عند بلوغ مضاعف الحد (15 ثم 30...). الإنذار «مبدئي» حتى يعتمده المدير. لا ارتباط بين الحضور والدرجات.

## الأمان
- الصلاحيات (مدير/معلم/ولي أمر) تُفرض **داخل الـ Worker** وليس بإخفاء الأزرار: المعلم يرى فصوله فقط، وولي الأمر يرى أبناءه فقط (مطابقة رقم هاتفه المسجل).
- كلمات مرور المستخدمين مخزّنة بـ PBKDF2 (ليست نصًا). لا توجد أسرار في ملفات الواجهة.
- **تغيير في دخول ولي الأمر:** أصبح (الكود + رقم الهاتف كاملًا) بدل آخر 4 أرقام، لأن 4 أرقام = 10,000 احتمال فقط. وعليه حد لمحاولات الخطأ.
- **تحذير عاجل:** ملف `script.js` القديم كان يحتوي رابط SheetDB «الإدارة» `4f6j4m9d8po12` علنًا، وأي شخص يملك الرابط يستطيع قراءة بيانات الطلاب. **احذف/عطّل هذا الـ API من لوحة SheetDB** واستخدم جدولًا جديدًا غير منشور.
- `students.csv` فيه أسماء وأرقام هواتف — لا ترفعه على GitHub عام.

## مشكلة التعليق عند الدخول — ما وجدته وما لم أستطع إثباته
- في قسم ولي الأمر القديم: **لا مهلة للطلبات** (لو تأخرت SheetDB يبقى «جاري التحميل» للأبد)، والأخطاء كانت تُبتلع (`return []`)، ويمكن الضغط على «عرض» عدة مرات. عدّلت: مهلة 20 ثانية، منع الإرسال المكرر، رسائل أخطاء عربية، وهذه المعالجات نفسها في `admin.js`.
- في `index.html` الخاص بـ AChat: التحويل إلى `chat.html` يحدث **مرتين** (من `onAuthStateChanged` ومن بعد نجاح الدخول). إن كان `chat.html` يعيدك لـ index قبل جاهزية Firebase فقد تحدث حلقة. **لم أستطع تأكيد السبب** لأن `chat.html` و`firebase-config.js` لم يصلا. لم أعدّل هذا الملف لأنه ليس جزءًا من «حضور».

## ما تم اختباره فعلًا وما لم يُختبر
- **اختُبر (آليًا):** `node worker/test.mjs` يشغّل الـ Worker مع SheetDB وهمي في الذاكرة: الحسابات، العطلات، الدخول، الصلاحيات (معلم/ولي أمر/مدير)، الإنذار التلقائي وعدم تكراره، الدرجات المرجّحة، الاستيراد. النتيجة: 18/18.
- **فُحص نحويًا فقط:** `admin.js` و`script.js` (`node --check`)، وفُحصت معرّفات العناصر ثابتًا.
- **لم يُختبر:** الواجهة في متصفح حقيقي، ولا التعامل مع SheetDB الحقيقي (افترضت صيغ DELETE/PATCH حسب توثيقه — جرّب أول مرة بيانات قليلة)، ولا تحميل مكتبة Excel من الإنترنت، ولا طباعة PDF.
- **PDF** = نافذة طباعة بالعربية → «حفظ بصيغة PDF» (لا توجد مكتبة PDF تدعم العربية بلا خطوط مرفقة). **Excel/CSV** ملفات حقيقية بالبيانات.
- **إرسال إشعار فعلي:** لا توجد خدمة SMS/واتساب مرتبطة. المتاح: الإشعار داخل حساب ولي الأمر + زر «واتساب» في صفحة الإنذارات يفتح رسالة جاهزة. للإرسال التلقائي يلزم مزوّد خدمة (WhatsApp Business API أو SMS).

## كيف تختبر
1. دخول: افتح `admin.html` بحساب المدير؛ جرّب كلمة مرور خاطئة (رسالة عربية) والضغط المتكرر على الزر (يُرسل مرة واحدة).
2. الحضور: «تسجيل الحضور» ← فصل ← علّم غائبات ← حفظ ← تظهر الأرقام في لوحة التحكم.
3. الإنذار: اجعل الحد 2 في الإعدادات، سجّل غياب طالبة يومين ← يظهر إنذار «بانتظار الاعتماد» ← اعتمده.
4. ولي الأمر: في `index.html#parent` ادخل الكود ورقم الهاتف ← «إشعارات المدرسة» ← «تحديد كمقروء».
5. التقارير: «الإحصائيات والتقارير» ← اختر نوع التقرير ← Excel/CSV/PDF وافتح الملف وراجع الأرقام.
6. معلم: أنشئ معلمًا لفصل واحد وتأكد أنه لا يرى غيره.
